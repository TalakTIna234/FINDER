# Setup Git - Istruzioni Rapide

## Step 1: Configura Git (Fai questo PRIMA di continuare)

Apri il terminale e esegui questi comandi (sostituisci con i tuoi dati):

```bash
git config --global user.name "Il Tuo Nome"
git config --global user.email "tua-email@example.com"
```

**Esempio:**
```bash
git config --global user.name "Mario Rossi"
git config --global user.email "mario.rossi@gmail.com"
```

## Step 2: Verifica Configurazione

```bash
git config --global user.name
git config --global user.email
```

Dovresti vedere i tuoi dati.

## Step 3: Continua con il Deploy

Dopo aver configurato Git, torna qui e continua con il deploy su Vercel.
